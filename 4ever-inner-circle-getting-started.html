Getting Started

You'll be the product lead.
Claude Code will be the developer.

Everything you need to begin, in order, with no jargon.

This guide walks you through every step — what to install on your computer, what accounts to create, what to say in your first session with Claude Code, and how to break Phase 1 into manageable pieces so you're never staring at a blank screen.

Work through it at your own pace. You don't need to do it all in one day.

How this works

Four tools, working together

You don't need to learn to code. You need to learn to direct. These four tools are the whole workflow — once they're set up, you mostly just talk to Claude Code in plain English.

01

Claude Code

A tool that runs on your computer in something called the Terminal. You type instructions to it in plain English ("build me a homepage that matches this mockup") and it writes the code, creates files, and explains what it's doing as it goes. It can read the mockup and roadmap files we've already created.

Think of it as a senior developer who lives in your laptop and will do exactly what you ask, then tell you what they did.
02

GitHub

A free service that stores every version of your project safely in the cloud. Every time Claude Code changes something, that change is saved here. If anything breaks, you can roll back to a working version. Think of it as Time Machine for your project.

03

Vercel

This is where your site actually lives on the internet. It connects to your GitHub account, and every time you push a change to GitHub, Vercel automatically updates the live site. No FTP, no uploading. It just works.

04

Supabase

The "backend" — where the database lives, where couples log in, where files (photographs) are stored. One service, replaces about five separate things. Free to start. Claude Code will set most of it up for you.

Setup checklist · One-time

Install & create accounts — about two hours

Do these in order, take your time. None of them require any technical knowledge to install — they're all standard "click download, click install" steps.

01
10 min

Install Node.js

The engine that runs Next.js (the framework your site will be built with).

Go to nodejs.org, download the LTS (Long Term Support) version for your operating system, and install it. Just click through the installer — accept defaults.

02
10 min

Install Git

The tool that connects your computer to GitHub.

On Mac: open Terminal and type git --version. If it isn't installed, your Mac will offer to install it. On Windows: go to git-scm.com and run the installer.

03
10 min

Install VS Code (optional but recommended)

A free editor where you can see and tweak files Claude Code creates. You won't write code here, but it's useful for poking around.

Go to code.visualstudio.com and install it.

04
5 min

Install Claude Code

Once Node.js is installed, open Terminal (Mac) or PowerShell (Windows) and type:

npm install -g @anthropic-ai/claude-code

Then sign in by typing claude and following the prompts. You'll log in with the same Claude account you use for everything else.

If you get a permissions error on Mac, prefix with sudo: sudo npm install -g @anthropic-ai/claude-code. It'll ask for your computer password.
05
15 min

Create your accounts

Sign up for these four services (all free to start):

GitHub

Free

vercel.com/signup

06
5 min

Decide on your domain

Where will the Inner Circle live? Most natural option is a subdomain of your existing site:

innercircle.4everphotos.uk

You don't need to set this up yet — just decide. You'll point it to Vercel later, once the site is live.

07
Later

Accounts you'll add when needed

Don't sign up for these yet. Add them only when you reach the feature that needs them:

Twilio (for SMS & WhatsApp) — when you reach the messaging engine.
Shopify (for The Edit shop) — when you're ready to add products.
Stripe (for gift registry payments) — in Phase 2.
WhatsApp Business via Meta — Phase 2, but Claude Code will help you start the application earlier because approval takes 4–8 weeks.

Your first session

The first time you talk to Claude Code

Once everything is installed, this is the entire first session. You don't need to know what to type — you just need to know what you want.

01

Create a folder for the project

Somewhere on your computer (Desktop is fine for now), create a new folder called 4ever-inner-circle.

Save the three files I've made for you — the mockup, the roadmap, and this guide — into that folder.

02

Open Terminal in that folder

Mac: Right-click the folder → "New Terminal at Folder"
Windows: Inside the folder, hold Shift + right-click → "Open PowerShell here"

03

Start Claude Code

Type:

claude

Claude Code opens. It'll greet you and wait for your first instruction.

04

Tell it what you're building

Copy and paste this. It's a complete, self-contained brief:

Hi Claude. I'm building a luxury wedding client portal called 4Ever Inner Circle. It sits behind my existing site, 4everphotos.uk, for clients who've booked our wedding photography services.

I have three files in this folder you should read first:
— 4ever-inner-circle-mockup.html (the visual design)
— 4ever-inner-circle-roadmap.html (the phased build plan)
— 4ever-inner-circle-getting-started.html (this guide)

I'd like to start with Phase 1 step by step. For today's first session, please:
1. Read all three files so you understand the project
2. Set up a brand-new Next.js project with TypeScript and Tailwind CSS in this folder
3. Configure it as a PWA (installable to home screen)
4. Build the homepage based on the mockup — exact brand colours, the script font (Yellowtail), the editorial spacing
5. Initialise it as a Git repository and help me push it to GitHub
6. Help me deploy it to Vercel so I can see it live

Walk me through each step. I'm not technical, so explain what you're doing as you go. Ask me before doing anything destructive.
Claude Code will then take over. It'll ask you questions, install things, create files. Don't worry — it'll explain everything. If anything doesn't make sense, just ask "what does that mean?" and it'll explain.
05

By the end of session one

You'll have:

— A live homepage at a temporary Vercel URL
— Your code stored safely on GitHub
— A real, working foundation to build on
— A surprisingly small amount of confusion

Phase 1, one session at a time

Twelve sessions to a working Inner Circle

Don't try to build everything in one go. Each session is a focused, achievable piece. Take a week between them if you need to. Test each piece properly before moving on.

1
Foundation & homepage live

Next.js project, PWA setup, the homepage from the mockup, deployed to Vercel.

2
All the mockup sections

Journey timeline, mood board, The Edit preview, Calm Corner, gift registry preview, footer.

3
Supabase & couple log-in

Connect Supabase. Build magic-link authentication. Couples receive an invitation email and click to enter.

4
The couple dashboard

The private welcome page. Wedding date, countdown, the cards for People, Mood, Edit, Calm, Registry.

5
"Your People" — the role manager

Add people with name, role, phone, email, WhatsApp opt-in. Store them in the Supabase database.

6
Message templates & scheduling logic

Define the message templates (best man at 8 weeks, etc.) and the engine that schedules them based on each person's role and the wedding date.

7
SMS via Twilio

Sign up for Twilio, plug it in, send a test message to yourself, then to a test "couple". Live.

8
Email via Resend

The longer, more considered messages. Welcome emails, supplier briefs, post-wedding sneak peeks.

9
Google Maps per role

Attach the right venue pin to each role-based message. Church for family, suite for bridesmaids, kitchen entrance for suppliers.

10
The Edit — Shopify embed

Connect your Shopify shop, embed it beautifully into the Inner Circle so it doesn't break brand.

11
GDPR, polish, accessibility

Cookie consent, data export, deletion flow, accessibility audit, performance polish.

12
Soft launch with one real couple

Onboard your first booked couple to the Inner Circle. Watch what they do. Take notes. This is Phase 1 complete.

Your daily workflow

How a session actually goes

Once you're set up, every session looks roughly the same. It becomes routine quickly.

01

Open Terminal in your project folder, type claude

Claude Code resumes — it remembers everything about your project.

02

Tell it what you want to do today

"Today I want to add the 'Your People' page where couples can add their bridal party." Be specific about what success looks like.

03

Let it work, ask questions

It'll explain what it's doing. If anything's unclear, ask — "why are we doing that?" or "show me what it looks like first". Don't be shy.

04

Test on your computer

Before anything goes live, Claude Code will run a local preview. Look at it in your browser. Does it look right? Does it feel right? Only deploy when you're happy.

05

Push to GitHub & Vercel deploys

Claude Code does this for you. Vercel automatically updates the live site in about 60 seconds.

06

End the session

Type /exit. Your progress is saved. Come back tomorrow.

Honest expectations

What this will actually be like

A few honest things, said upfront, so nothing surprises you later.

~
You'll spend 60–100 hours on Phase 1

Spread over 6–12 weeks of part-time work. An hour or two most days, longer sessions on weekends. You're saving £25–40k of agency time, but you're spending your own.

~
You'll learn the language as you go

Words like "deploy", "commit", "environment variable" will become familiar within a few weeks. You don't need to learn them upfront — Claude Code will explain when they come up.

~
Things will sometimes break

This is normal. Software is messy. When something goes wrong, paste the error into Claude Code — it'll explain and fix it. You won't be stuck.

~
The first hour will be slowest

Just getting the setup done. By session three, you'll be moving quickly.

~
Save the message templates as written content first

The best-man tips, the bridesmaid notes, the supplier outreach — these need to be written in your voice, not generated. Spend a few days writing them before session 6, so the messaging engine has real content to send.

~
You can come back to me anytime

I'm here in Cowork mode for the planning, the design, the strategy, the difficult product decisions. Claude Code is your developer. The two of us work together, just on different parts of the job.
